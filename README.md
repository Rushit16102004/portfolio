# Rushit Bodra — AI & Machine Learning Developer Portfolio

Personal developer portfolio showcasing machine learning architectures, automated time-series systems, and AI agent platforms.

## 🚀 Featured Case Studies
1. **AI Algo Trading Console**: Real-time ML/RL trading and risk console with regime classification, TCN sequence modeling, LightGBM, and Thermal Dissipation lot sizing across 1.2M+ time-series records.
2. **ReplyBridge — AI Email First Responder**: Production SaaS application built with Next.js, FastAPI, Google Gemini API, and OAuth 2.0 to safely triage incoming Gmail messages and schedule context-aware acknowledgements.
3. **AI Company Research Assistant**: Autonomous agent pipeline that crawls target domains, maps competitor intelligence, synthesizes SWOT reports via Gemini 2.5, and outputs ReportLab PDFs.
